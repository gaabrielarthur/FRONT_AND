# Projeto Web Design - Gabriel Arthur

Bem-vindo ao meu projeto de Web Design! Este repositório contém a estrutura de um site front-end (Barberia GGSTUDIO), desenvolvido como parte dos meus estudos e práticas na área de desenvolvimento web.

## 📁 Estrutura do Projeto

O projeto está organizado da seguinte forma para manter o código limpo e fácil de entender:

*   **`index.html`**: É o arquivo principal do projeto. Ele contém toda a estrutura e o conteúdo da página web (marcação HTML).
*   **`CSS/`**: Pasta responsável por armazenar as folhas de estilo. É aqui que fica o código que dá cor, layout e vida à página, separando o design da estrutura.
*   **`imagem/`**: Diretório dedicado a guardar todas as imagens e recursos visuais utilizados no site (como logotipos, fotos e ícones).
*   **`vídeo/`**: Pasta onde estão armazenados os arquivos de mídia em vídeo que foram integrados ao projeto.
*   **`estrutura de arame/`** (Wireframes): Esta pasta contém os esboços iniciais e o planejamento do layout (wireframes) que serviram como guia visual antes da programação iniciar.

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Para a estruturação e semântica da página.
*   **CSS3:** Para a estilização e design responsivo.
